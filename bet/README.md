# bet — アプリの🔥（9車・5〜15倍）とモデルDをオッズパークで自動購入する

Windows のPC（締切前オッズを取っている、あのPC）で動かします。
競艇の `auto_bet`（v24）と同じ作りで、**同時に動かせます**（フォルダも Chrome のプロファイルも別）。

**ログインID・パスワード・暗証番号はどこにも保存しません。** 起動すると Chrome が開くので、
そこに自分で入れます。このプログラム・設定ファイル・ログのどこにも入りません
（config.json に `password` などの項目を書くと、起動を止めます）。

## 何を買うか ― アプリと同じ（2026-09-27 に見直し。keirin の hikitsugi §4-12）

| | |
|---|---|
| **モデルD** | 全レースの3連複全組から、`evd.js` の期待値が **1.05以上・20倍以下の組を全部**（`buy_model_d`）。ふつう1レース1点・多くて4点。1日平均5点ほど（2026-09-29 から。keirin の hikitsugi §4-14） |
| **🔥 9車立て** | 本命ライン3人の3連複1点。既定は締切前の倍率が **5〜15倍の中** のときだけ（`hot9_mode`。下の表） |
| 🔥 7車立て | **既定では買わない**（`hot7_mode`。帯は4〜15倍） |

🔥の買い方（`hot9_mode` / `hot7_mode`。run.bat の 7) 設定から番号で選べる。2026-10-01〜）

| 値 | 買うとき | 9車 5年の回収・収支 | 7車 5年の回収・収支 |
|---|---|---|---|
| `both` | 期待値1以上 **かつ** 帯の中 | 118.2%・+16,090円 | 103.3%・+4,160円（3年マイナス） |
| `ev` | 期待値1以上だけ（帯は見ない） | 113.5%・+21,560円 | 98.2%・−3,190円 |
| `band` | 帯の中だけ（期待値は見ない） | **111.2%・+30,990円（9車の既定）** | 93.7%・−22,910円 |
| `either` | 期待値1以上 **または** 帯の中 | 110.5%・+36,460円 | 92.8%・−30,260円 |
| `all` | 🔥を全部（倍率が届かなくても買う） | 102.0%・+11,320円 | 86.2%・−81,000円 |
| `off` | 買わない | — | **（7車の既定）** |

2022〜2026年9月・確定オッズ・S級S班のいるレースを除く。期待値はアプリと同じ ev.js（係数は2025年のデータで作ったので、2025年の数字は少し良く出る）。
`hot9_mode` / `hot7_mode` を書かなければ、古い設定（`hot9_use_ev`・`buy_7car_hot`・`use_ev_7car`）から決める。
| 重なり | モデルDの組が🔥と同じなら1点だけ（🔥を買ったらモデルDのその組は重ねない） |
| いつ決めるか | **締切2.5分前まで待ち、いちばん新しい倍率で1回だけ**（締切6分前からは全レースの倍率を1分おきに取るので、ふつう締切2.5〜3.5分前の倍率） |
| 1点 | 100円 |

5年分（2022〜2026年）の作り直した出走表で、前の年までのデータで作って次の年で試した成績（確定オッズ）:

| | 2022 | 2023 | 2024 | 2025 | 2026 |
|---|---|---|---|---|---|
| モデルD（期待値1.05以上・20倍以下を全部。的中11〜12%） | — | 103% | 102% | 123% | 115% |
| 🔥9車・5〜15倍（S級S班がいるレースは見送り） | 103% | 103% | 103% | 132% | 103% |

（2026-09-28 に S級S班の選手の読み漏れを直して作り直した数字。hikitsugi §4-13）

判定は keirin の **`betplan.js`** が出します（アプリと同じ `evd.js` / `ev.js`）。Python 側では計算し直しません。
今日の判定は `run.bat` の `5)` か、`node ..\betplan.js --pretty` で一覧できます。

- 締切2.5分前より前の倍率では決めません。1度決めたら決め直しません
- モデルDは全レースを見るので、買う組が無いレースは記録もログもしません（買う組があったレースだけ出ます）
- 倍率は PC の `snap.js` が取っているもの（`snapwork/`）。PC の記録が止まっていれば GitHub（odds-live）のものを使います
- 締切は「発走の5分前」。オッズパークの「レースまとめ投票」でそのレースのチェック欄が消えていれば買いません
- `bet_done.json` のキーは🔥が `日付_場_R`、モデルDが `日付_場_R_D`（2点目から `_D2` `_D3` `_D4`）。モデルDの組は締切2.5分前に1回だけ決め、あとで倍率が動いて組が増えても買い足しません（2点目以降が失敗したときだけ次の周に買い直します）

★成績は**確定オッズで測った数字**です。締切前の倍率で同じになるかは、締切前オッズの記録で確かめている途中です。
当たるのは11〜12%（モデルD。9レースに1回くらい）なので、月ごとの波は大きい。

## 最初にすること

### 1. 入れる（競艇の auto_bet を動かしているなら済んでいます）

```
python -m pip install playwright
```

お使いの Chrome がそのまま使われます（`use_installed_chrome: true`）。

### 2. 場所

keirin の PC 設定で入れたフォルダの中にあります:

```
C:\keirin\keirin\bet\run.bat   ← これをダブルクリック
```

PC のタスク（runner.js）が10分おきに GitHub を取り込むので、**直したものは自動で届きます**
（Python の部分は、動かし直したときに新しくなります）。
`config.json`・`bet_done.json`・`chrome_profile\`・`logs\`・`shots\` は git に入らず、消されません。

データを合言葉で暗号化しているときは、先に `C:\keirin\keirin\pc\set_pass.bat` で合言葉を入れておくこと
（無いと出走表を読めず、ログに「合言葉が設定されていません」と出て何も買いません。keirin の hikitsugi §4-22）。

デスクトップから開きたいときは `run.bat` を右クリック →「送る」→「デスクトップ (ショートカットを作成)」。

### 3. 上げていく順番 ★飛ばさないこと

1. **`check` を数日** ― アプリの🔥カード（期待値・✓買い／✗見送り）と、ログの判定が合っているか見る
2. **`4) ためす` で画面を1回通す** ― いま発売中のレースを指定して、確認画面まで進むか
3. **`dry` を数日** ― `shots\` の確認画面のスクショを毎回見る
4. **利用規約を読み、`7)` → `1)` で live を使えるようにする**
5. **`live` を1日1レースだけ**（`7)` で「1日の上限（レース数）」を1に）
6. 慣れたら上限を戻す

## 5つのメニュー（run.bat）

```
 1) check   買う／見送るの判定を見るだけ（ブラウザ無し）
 2) dry     ブラウザを開き、確認画面まで進んで押さない
 3) live    実際に購入する（y を入れて確認してから動きます）
 4) ためす   疑似の買い目で dry を試す（買い目が無い時間用）
 5) 今日の勝負レースと判定を一覧で見る
 6) 画面操作を記録する（手で投票した手順を残す。作り直し用）
 7) 金額や上限の設定を変える
 8) ログの最後の30行を見る
 9) テスト（サイトを触らずに確かめる）
```

`dry` / `live` では Chrome が開きます。**開いた Chrome でオッズパークに手でログイン**
（暗証番号の画面まで）→ 黒い画面で Enter → あとは自動です。Chrome は閉じないでください。

続けて投票の窓（別ウィンドウ）が開き、**「本人確認」でパスワードを聞かれたら、その窓で手で入れて「確認」**を押します
（プログラムは入れません。黒い画面に「★投票の窓で「本人確認」…」と出て、最大5分待ちます）。

コマンドで動かすなら:

```
python keirin_bet.py --mode check
python keirin_bet.py --mode dry
python keirin_bet.py --mode live
python keirin_bet.py --mode dry --fake 広島-1-3-4-6     疑似の買い目（dry / check だけ）
python keirin_bet.py --mode check --once                1周だけ
```

**既定のモードはありません。** `live` は `config.json` の `i_have_read_the_terms` が `true` のときだけ
起動します。これは「オッズパークの利用規約を自分で読んで、自動操作について問題ないと判断した」という
**あなた自身の記録**です。

### 6) 画面操作を記録する（別の投票画面を使いたいとき・動かないとき）

Chrome が開くので、**ふだんどおり手で**ログインして、使いたい投票画面で1レースぶん
（場 → レース → 3連複 → 車番3つ → 100円 → 確認画面）操作し、黒い画面で Enter。
`records\日時\` と `records\日時.zip` に残ります:

- `steps.txt` … 押したところ・入れたところの一覧（どのボタンか・id・リンク先など）
- `NN_窓1.png` / `.html` … 画面が変わるたびのスクショと HTML（枠の中も）

これを見せてもらえれば、その画面に合わせて `oddspark_page.py` を作り直せます。

- **ID・パスワード・暗証番号は残しません**（入れた文字は「（伏せた・N文字）」。金額などの1〜3桁の数字だけ残す）。
  ログイン・暗証番号の画面は撮りません。HTML からも入力欄の中身・隠し欄・スクリプトを消しています
- ★画面に出ている**残高・お名前・会員番号**は写ります。見せる前に確かめてください
- ★「よろしいですか？」の小窓（ダイアログ）は自動でキャンセルされます（文面は記録に残ります）
- 購入まで押すと本当に買えます。確認画面まででも十分です
- 自動購入（2・3）と同じ Chrome のプロファイルを使うので、同時には動かせません

## 設定（config.json）

`run.bat` の `7)` から変えられます（おかしな値は保存されません）。無ければ `config.example.json` から作られます。

| 項目 | 既定 | 意味 |
|---|---|---|
| `i_have_read_the_terms` | false | true にするまで live は動かない |
| `bet_yen` | 100 | 1点あたり |
| `max_yen_per_day` | 2500 | 1日の上限（円）。null で無制限 |
| `max_races_per_day` | 25 | 1日の上限（**点数**。モデルDの2点目も1と数える）。ふつう1日6〜7点・多い日で20点ほど。**当たったら何かおかしい** |
| `buy_model_d` | true | モデルD（全レース・期待値1.05以上・20倍以下の組を全部）を買う |
| `hot9_mode` | band | 🔥9車立ての買い方（both / ev / band / either / all / off。上の表） |
| `hot7_mode` | off | 🔥7車立ての買い方（同じ） |
| `hot9_use_ev`・`buy_7car_hot`・`use_ev_7car` | — | 古い設定。`hot9_mode` / `hot7_mode` が無いときだけ読む |
| `decide_at_minutes` | 2.5 | 締切まで何分になったら決めるか（そのときのいちばん新しい倍率で1回だけ） |
| `max_snap_age_minutes` | 4 | これより古い倍率では決めない |
| `close_min_minutes` | 1.5 | 締切まで何分を切ったら買わないか |
| `require_site_close` | true | オッズパークの画面で発売中を確かめられないレースは live で買わない |
| `payment_method` | opcoin | 支払い方法。opcoin=OPコイン / cash=投票資金 |
| `poll_seconds` | 20 | 何秒おきに判定を見るか |
| `keepalive_minutes` | 10 | 買うものが無い間、何分おきにトップを読み直すか（0 で何もしない） |
| `vote_link_index` | 2 | トップの「投票する」のうち競輪のものが見分けられないときに押す順番（0から） |
| `ntfy_topic` | （空） | 通知先の ntfy のトピック名。空なら通知しない（下の「スマホに通知する」） |
| `ntfy_server` | https://ntfy.sh | ntfy のサーバー（自分で立てたものを使うときだけ変える） |
| `ntfy_in_dry` | false | dry でも通知する（確認画面まで進んだとき。設定を試す用） |

上限は使いすぎ防止ではなく**バグ避け**です。使った額・レース数は `bet_done.json` の当日分から数えます。

## スマホに通知する（ntfy）

live で動かしているとき、次のことが起きたらスマホに通知します。期待値1未満などの普通の見送りは送りません。

| 通知 | いつ | 優先度 |
|---|---|---|
| 購入しました | 購入できた（場・R・買い目・金額・当日計） | ふつう |
| 購入に失敗しました | 画面操作の失敗・ログイン切れ（次の周でもう一度試す） | 高 |
| 買えずに見送りました | 買うつもりだったが、発売していない・締切が近い・2回失敗した | 高 |
| ★購入できたか分かりません | 購入を押した後に結果が読めなかった（投票履歴で確かめる） | 最高 |
| 自動購入が止まりました | ログインが戻らない・記録できない・思わぬエラーなどで止まった | 最高 |

1. スマホに **ntfy** アプリを入れる（無料。Android / iPhone）
2. `run.bat` の `7)` → 「通知先（ntfy のトピック名）」に名前を入れる。**★知っている人は誰でも読めるので、推測されにくい名前にする**（半角の英数字・_・-）。その画面に毎回乱数で作った「おすすめ」が出るので、`+` を入れればそれを使える
3. アプリでその名前のトピックを購読する
4. `7)` の「通知を試しに1通送る」で届くか確かめる（`python keirin_bet.py --notify-test` でも同じ）

- 通知に入れるのは 場・R・買い目・金額・理由だけです。残高・ログイン情報は入れません
- 送れなくても（ネットが切れていても）購入の処理は止まりません。ログに「通知できず」と残ります

## 止め方

- このフォルダに `STOP` という名前のファイルを作る → 次の周で止まります（動かす前に消すこと）
- Ctrl+C → その場で止まります

## 二重購入を防ぐしくみ

- 記録は `bet_done.json`。キーは `日付_場_レース`（例 `20260926_岐阜_3R`）。**キーがあれば何があっても買わない**
- **「購入する」を押す直前に書きます。書けなければ押しません**
- 見送りと決めたレースも金額0で書きます（決め直さない）
- セットした後の買い目一覧と確認画面の表を読み返して、**場・R・3連複・組・金額100円・1通り**を照合し、合わなければ押しません。
  買い目一覧に前の残りがあれば、先に「全買い目削除」で消してから入れます
- 押した後で画面が読めない・受付の画面か分からないときは、**買ったものとして記録して止まります**（終了コード4）。
  オッズパークの投票履歴を見て、買えていなければ `bet_done.json` のその行（note に「要確認」）を消してください
- 押す前に画面操作が失敗したら、買い目一覧を片付けてその周は打ち切り。同じレースで2回失敗したら見送り
- `bet_done.json` が壊れていたら起動しません（終了コード3）

| 終了コード | |
|---|---|
| 0 | 正常（STOP / Ctrl+C を含む） |
| 2 | 設定や準備が足りない（規約フラグ、ログインできない、Node や betplan.js が無い など） |
| 3 | bet_done.json が壊れている |
| 4 | 購入の結果が分からない／記録できないので止めた |

## オッズパークの画面（「レースまとめ投票」を使う）

2026-09-26 に記録モード（`6)`）で採った実物の操作から作りました。手順:

1. トップの競輪の「投票する」→ 別ウィンドウが開く（いったん「Loading」を挟む）
2. 「レースまとめ投票」を押す
3. 前の買い目一覧が残っていれば「全買い目削除」、前の選択（車番・レース・賭式）も消す
4. セット金額に「1」（100円）→ 車番の表で 1着列・2着列・3着列に1車ずつ（三連複フォーメーション＝1通り）
5. レース選択の表で、そのレースのチェック欄（`日付_場コード_R`）に印 → 賭式は「3連複」だけ → 支払い方法
6. 「セット」→ **買い目一覧が1行・場・R・3連複・組・組数1通り・合計100円か照合**
7. 「投票手続へ」→ **投票申込確認の表が1行・開催場・R・3連複・買い目・100円・合計100円か照合**
8. dry はここで「戻る」→「全買い目削除」。live は「投票を申込」→ 完了画面の「受付 ○」を確かめて「続けて購入する」

- 締め切ったレースはチェック欄が消えるので、欄が無ければ買いません。締切の時刻は画面に出ないので、発走の5分前を使います
- オッズパークの車立て（表の「9車」など）が予想と違えば、別のレースの恐れがあるので買いません
- 支払い方法は **OPコイン**（既定）か **投票資金**。`7)` の「支払い方法」で変えられます
- 買い目一覧・確認画面・完了画面の照合は、実物の画面（記録モードで採ったもの）で確かめてあります

**dry で止まったら**、`shots\` のその時刻のスクショ（`.png`）と画面（`.html`）を見せてください。
★残高やお名前が写ることがあります。見せる前に確かめてください。
画面の作りが変わったときは、`6)` でもう一度記録してもらえれば作り直せます。

# bet — アプリの🔥（期待値で絞ったもの）をオッズパークで自動購入する

Windows のPC（締切前オッズを取っている、あのPC）で動かします。
競艇の `auto_bet`（v24）と同じ作りで、**同時に動かせます**（フォルダも Chrome のプロファイルも別）。

**ログインID・パスワード・暗証番号はどこにも保存しません。** 起動すると Chrome が開くので、
そこに自分で入れます。このプログラム・設定ファイル・ログのどこにも入りません
（config.json に `password` などの項目を書くと、起動を止めます）。

---

## 何を買うか ― アプリと同じ

| | |
|---|---|
| 対象 | アプリの🔥（本命ライン3人の3連複1点。`races.json` の `plan.ticket`） |
| 期待値 | **1以上だけ買う**（アプリの「期待値で絞る」と同じ式。`ev.js`） |
| 7車立て | 締切前の倍率が **帯 4〜15倍の中** のときだけ（アプリと同じ） |
| いつ決めるか | **締切まで6分以内に取った倍率**が届いた時点で1回だけ（ふつう締切3〜6分前の倍率） |
| 1点 | 100円 |

判定は keirin の **`betplan.js`** が出します（アプリと同じ `ev.js`）。Python 側では計算し直しません。
今日の判定は `run.bat` の `5)` か、`node ..\betplan.js --pretty` で一覧できます。

- 1度「見送り」と決めたレースは、あとで倍率が動いても買いません（何度も見て「買い」を拾うと、
  検証していない別のルールになるため）
- 倍率は PC の `snap.js` が3分おきに取っているもの（`snapwork/`）。PC の記録が止まっていれば
  GitHub（odds-live）のものを使います
- 締切は「発走の5分前」。オッズパークの画面に出ている締切が早ければ、そちらに合わせます

★期待値の「1以上で約121%」は**確定オッズで測った数字**です。締切前の倍率で同じになるかは、
まだ記録を貯めて確かめている途中です（`snap_eval.js`）。

## 最初にすること

### 1. 入れる（競艇の auto_bet を動かしているなら済んでいます）

```
python -m pip install playwright
```

お使いの Chrome がそのまま使われます（`use_installed_chrome: true`）。

### 2. 場所

keirin の PC 設定で入れたフォルダの中にあります:

```
C:\keirin\keirin\bet\run.bat   ← これをダブルクリック
```

PC のタスク（runner.js）が10分おきに GitHub を取り込むので、**直したものは自動で届きます**
（Python の部分は、動かし直したときに新しくなります）。
`config.json`・`bet_done.json`・`chrome_profile\`・`logs\`・`shots\` は git に入らず、消されません。

デスクトップから開きたいときは `run.bat` を右クリック →「送る」→「デスクトップ (ショートカットを作成)」。

### 3. 上げていく順番 ★飛ばさないこと

1. **`check` を数日** ― アプリの🔥カード（期待値・✓買い／✗見送り）と、ログの判定が合っているか見る
2. **`4) ためす` で画面を1回通す** ― いま発売中のレースを指定して、確認画面まで進むか
3. **`dry` を数日** ― `shots\` の確認画面のスクショを毎回見る。ログの「サイトの締切」が読めているか
4. **利用規約を読み、`7)` → `1)` で live を使えるようにする**
5. **`live` を1日1レースだけ**（`7)` で「1日の上限（レース数）」を1に）
6. 慣れたら上限を戻す

## 5つのメニュー（run.bat）

```
 1) check   買う／見送るの判定を見るだけ（ブラウザ無し）
 2) dry     ブラウザを開き、確認画面まで進んで押さない
 3) live    実際に購入する（y を入れて確認してから動きます）
 4) ためす   疑似の買い目で dry を試す（買い目が無い時間用）
 5) 今日の勝負レースと判定を一覧で見る
 7) 金額や上限の設定を変える
 8) ログの最後の30行を見る
 9) テスト（サイトを触らずに確かめる）
```

`dry` / `live` では Chrome が開きます。**開いた Chrome でオッズパークに手でログイン**
（暗証番号の画面まで）→ 黒い画面で Enter → あとは自動です。Chrome は閉じないでください。

コマンドで動かすなら:

```
python keirin_bet.py --mode check
python keirin_bet.py --mode dry
python keirin_bet.py --mode live
python keirin_bet.py --mode dry --fake 広島-1-3-4-6     疑似の買い目（dry / check だけ）
python keirin_bet.py --mode check --once                1周だけ
```

**既定のモードはありません。** `live` は `config.json` の `i_have_read_the_terms` が `true` のときだけ
起動します。これは「オッズパークの利用規約を自分で読んで、自動操作について問題ないと判断した」という
**あなた自身の記録**です。

## 設定（config.json）

`run.bat` の `7)` から変えられます（おかしな値は保存されません）。無ければ `config.example.json` から作られます。

| 項目 | 既定 | 意味 |
|---|---|---|
| `i_have_read_the_terms` | false | true にするまで live は動かない |
| `bet_yen` | 100 | 1点あたり |
| `max_yen_per_day` | 1000 | 1日の上限（円）。null で無制限 |
| `max_races_per_day` | 10 | 1日の上限（レース）。**当たったら何かおかしい** |
| `use_ev` | true | 期待値1以上だけ買う。false なら🔥を全部（7車は帯の中だけ） |
| `buy_7car` | true | 7車立ても買う |
| `decide_left_minutes` | 6 | 締切まで何分以内に取った倍率で決めるか |
| `max_snap_age_minutes` | 4 | これより古い倍率では決めない |
| `close_min_minutes` | 1.5 | 締切まで何分を切ったら買わないか |
| `require_site_close` | true | オッズパークの画面から締切が読めないレースは live で買わない |
| `poll_seconds` | 20 | 何秒おきに判定を見るか |
| `keepalive_minutes` | 10 | 買うものが無い間、何分おきにトップを読み直すか（0 で何もしない） |
| `vote_link_index` | 2 | トップの「投票する」のうち競輪のものが見分けられないときに押す順番（0から） |

上限は使いすぎ防止ではなく**バグ避け**です。使った額・レース数は `bet_done.json` の当日分から数えます。

## 止め方

- このフォルダに `STOP` という名前のファイルを作る → 次の周で止まります（動かす前に消すこと）
- Ctrl+C → その場で止まります

## 二重購入を防ぐしくみ

- 記録は `bet_done.json`。キーは `日付_場_レース`（例 `20260926_岐阜_3R`）。**キーがあれば何があっても買わない**
- **「購入する」を押す直前に書きます。書けなければ押しません**
- 見送りと決めたレースも金額0で書きます（決め直さない）
- 確認画面の文字を読み返して、**場・R・3連複・組・合計金額（100円）・1点**を照合し、合わなければ押しません。
  ベットリストに前の買い残りが混ざっていれば、ここで止まります
- 押した後で画面が読めない・受付の画面か分からないときは、**買ったものとして記録して止まります**（終了コード4）。
  オッズパークの投票履歴を見て、買えていなければ `bet_done.json` のその行（note に「要確認」）を消してください
- 押す前に画面操作が失敗したら、ベットリストを片付けてその周は打ち切り。同じレースで2回失敗したら見送り
- `bet_done.json` が壊れていたら起動しません（終了コード3）

| 終了コード | |
|---|---|
| 0 | 正常（STOP / Ctrl+C を含む） |
| 2 | 設定や準備が足りない（規約フラグ、ログインできない、Node や betplan.js が無い など） |
| 3 | bet_done.json が壊れている |
| 4 | 購入の結果が分からない／記録できないので止めた |

## ★オッズパークの画面について（まだ確かめきれていないこと）

画面の操作は、利用者が `playwright codegen` で採取した1レースぶんの流れから作りました
（`oddspark_page.py`）。**私（Claude）はオッズパークに接続できない環境にいて、実物の画面を
一度も見ていません。** テストは、採取したセレクタを真似た偽の画面（`tests/fake_site/`）で通しています。

採取からの流れ: トップ →「投票する」（別ウィンドウが開く）→ 場 → レース → `#mode1` 通常 → 連複 →
`#mode3` 通常 → `#row1_{車}` `#row2_{車}` `#row3_{車}` → `#textfield11` に「1」→ セット → 投票手続へ →
購入する → 続けて購入する

まだ採取できていないので、**画面の文字から読んでいるもの**（読めなければ買わない側に倒します）:

| もの | いまのやり方 | dry で確かめること |
|---|---|---|
| 締切 | 画面の「締切 HH:MM」を探す | ログに「サイトの締切 15:23」と出るか |
| 確認画面の合計 | 「合計 … 100円」を探す | 確認画面で止まらず「確認画面まで」と出るか |
| ログイン済み | 「ログアウト」の文字 | 起動時に「ログインを確かめました」と出るか |
| 競輪の「投票する」 | リンク先に keirin / 周りに「競輪」 | ログに「競輪の「投票する」」と出るか |
| 9車立て | `#row*_8` `#row*_9` があるか | 9車のレースで止まらないか |
| ベットリストの消し方 | 「戻る」→「取消」などを押してみる | dry のあと「片付けました」と出るか |
| 受付の画面 | 「受付」「完了」の文字か「続けて購入する」 | live の最初の1レースで要確認にならないか |

**dry で止まったら**、`shots\` のその時刻のスクショ（`.png`）と画面（`.html`）を見せてください。
★`.html` と `.png` には残高やお名前が写ることがあります。見せる前に確かめてください。
★codegen で採り直すときは、出てきたコードの `fill("…")` の行にID・パスワード・暗証番号が入ります。
必ず消してから貼ってください。
